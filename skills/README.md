# Game dev skill library

| Skill | Area | Use when |
|---|---|---|
| game-core-loop | Programming | structuring the loop and phases |
| canvas-2d-rendering | Programming | drawing sprites and scenes on canvas |
| pixel-art-sprites | Design/Art | creating or revising sprites |
| game-animation | Design/Art | motion, anticipation, loops |
| game-vfx-feedback | Design/Art | particles, floaters, reward feedback |
| idle-game-economy | Design | costs, rates, drop tables, offline gains |
| icon-first-ui | Design | symbol-based HUD and menus |
| game-save-state | Programming | persistence and validation |
| game-design-doc | Design | planning a game or feature |
| game-testing-balance | Programming/Design | verifying logic and tuning |

Each folder holds one SKILL.md with YAML frontmatter (name, description).
